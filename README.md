# Assignment 4 — Forms and Validation

**Student:** Serikov Sunggat  
**Group:** SE-2528

A project demonstrating HTML forms, HTML5 validation, Bootstrap styling, and responsive layouts.

## Pages

- `index.html` — Basic contact form.
- `task1.html` — Contact form with HTML5 validation.
- `task2.html` — Bootstrap form styling and grid.
- `task3.html` — Manually applied Bootstrap validation classes.
- `task4.html` — Registration form with validation feedback, radio buttons, checkboxes, country selection, and Reset.

## How to Run

Open `index.html` in a browser. Use the navbar to switch pages. Internet access is required to load Bootstrap.

## Technologies

HTML5 and Bootstrap 5.3.8.
